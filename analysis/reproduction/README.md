Construction and review provenance scripts. Native hardware files are the authoritative final design. build_design.py creates an unrouted initial placement and would overwrite later routing; do not run it on the final project without a backup. Scripts require KiCad 10 Python/pcbnew, sexpdata, Shapely and NumPy and contain this machine's paths. They are provenance, not a portable one-command reproduction system. Routing candidates and logs record intermediate rejected results.
